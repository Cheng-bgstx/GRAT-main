## 1. 理论框架 (CODD)

### 核心公式
```
ΔF(ω) = F_target(ω) - F_source(ω)
在源载波基 e^{j·φ_s} 中分解：
  ΔG = ΔF · e^{-j·φ_s} = α + j·β
  α = 径向 (载波对齐) → rr = E[α²]/(E[α²]+E[β²])
  β = 切向 (载波正交)

rr = 0.5: 各向同性 (随机基线)
rr > 0.5: 径向占主导 → 微调主要在幅度维度上调整
```

## 2. 攻击方法

### 在线阶段
```
对每张测试图像 x:
  1. FFT 特征: F(ω) = A(ω)·exp(j·φ(ω))
  2. 载波对齐探针: ΔA = N(0,1)·(λ·A + γ)
  3. 相位锁定: δ = IFFT(ΔA·exp(j·φ))
  4. 损失: L1(F_adv, F_clean) + L1(drift - probe)
```

## 5. 方法描述 (最终版)

**CODD (Carrier-Oriented Drift Decomposition)** 是一种基于频域载波分解理论的对抗攻击框架,
用于 SAM 及其医学下游模型的黑盒迁移攻击。

**理论**：将基础 SAM 和微调模型之间的 ViT 特征漂移在源载波基中分解，发现径向（载波对齐）
分量在全部 18 个微调模型中占主导 (rr=0.54-0.70, 显著高于随机基线 0.50)。这意味着源相位
方向是模型间共享的结构锚点。

**离线阶段**：从代理数据集收集载波对齐攻击梯度，通过 PCA 提取 Shared Radial Subspace (SRS)，
捕获通用的脆弱性方向。SRS 用于在线阶段的动量初始化和梯度投影。

**在线阶段**：生成载波对齐的频域扰动——高斯噪声沿源载波方向调制, 相位锁定于干净特征。
通过动量累积和 ε-ball 投影进行迭代优化。SRS 投影防止对白盒代理模型的过拟合。

**验证**：在 ISIC 2016 数据集上, CODD 攻击在 5/6 黑盒受害者模型上降低了分割精度 (平均
Dice 下降 0.025, 最大 0.081)。方向性烧蚀验证了载波对齐机制的有效性，同时揭示了切向扰动
对 MSA 受害者有额外破坏性。完整的 18 模型理论验证确立了 CODD 作为频域对抗迁移攻击的
原则性框架。
